# manas-live-traker


## Installation
1. **Clone the repository**:
```bash
git clone https://github.com/manasalbum321-dotcom/manas-live-tracker.git
cd manas-live-traker
```

2. **Install dependencies**:
```bash
npm install
```

3. **Run the application:**
```bash
npm start
```

4. Login credentials
```js
username: manas.in
password: manas.in
```
